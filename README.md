# Tuloy Dance Studio

Simple static dance studio mockup for scraper testing: Home, Programs, and Contact Us. No backend.

## Deploy to Vercel

Import `b4didot/tuloykayo` into Vercel. Keep the Root Directory at the repository root and use `main` as the production branch. The included `vercel.json` configures the build and output directory; no environment variables are needed.

## Local use

Open `dance-studio/dist/index.html` in a browser. Regenerate the pages and validate content and links with `node dance-studio/generate.mjs`.
