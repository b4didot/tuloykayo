# Tuloy Dance Studio mockup

Three static pages, with no backend or JavaScript dependency. Open `dist/index.html` directly, or serve `dist` with any static web server. All supplied facts appear in the HTML source.

To regenerate and check the pages: `node generate.mjs`. Content and layout templates are stored in `generate.py`; Python is not required.

The contact page provides the supplied address, hours, parking, and trial information. No working submission form or invented contact details are included.
